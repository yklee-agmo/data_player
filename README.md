# Data Player

이미지 폴더와 동영상을 **같은 방식(프레임 단위)** 으로 재생하는 PyQt6 GUI 뷰어입니다.

## 할 수 있는 것

- **이미지 폴더 열기** — 폴더 안의 이미지를 번호순으로 정렬해 동영상처럼 이어서 재생
- **동영상 열기** — ffmpeg 로 디코딩해 재생 (mp4, avi, mov, mkv, webm ...)
- **배속 조절** — 0.1x ~ 10x, 두 경우 모두 동일하게 적용
- **번호로 이동** — 원하는 번호를 넣으면 그 화면으로 바로 이동
  - `순번` 모드: 1 ~ 전체 개수 (동영상은 프레임 번호)
  - `파일 번호` 모드: 파일명의 숫자로 이동 (예: `frame_0025.png` → `25`)
    없는 번호를 넣으면 가장 가까운 번호로 이동하고 상태 표시줄에 알려 줍니다.
- **재생 바 클릭 이동** — 재생 바의 원하는 위치를 클릭하면 그 지점으로 바로 갑니다 (그대로 끌어서 이어 이동해도 됩니다)
- **멀티 뷰** — 화면을 나눠 여러 동영상 / 이미지 폴더를 나란히 놓고 동시에 재생
- **구간 잘라 저장** — 원하는 구간을 표시해 **이미지 프레임 폴더** 또는 **동영상 파일** 로 저장

## 멀티 뷰 (여러 영상 비교)

툴바의 **멀티 뷰** 버튼을 누르면 단일 화면과 4분할이 번갈아 바뀝니다.
버튼 옆 화살표를 누르면 `1x2`, `2x1`, `2x2`, `1x3`, `2x3`, `3x3` 중에서 고를 수 있고
`모든 화면 선택 / 선택 해제 / 비우기` 도 이 메뉴에 있습니다.

나뉜 각 화면(칸)은 **자기만의 파일, 현재 프레임, 배속, 재생 시계**를 갖습니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 칸에 파일 열기 | 칸에서 **우클릭 → 동영상 열기 / 이미지 폴더 열기** (칸에 끌어다 놓아도 됩니다) |
| 여러 영상 동시 재생 | 함께 볼 칸의 **체크박스를 켜고** 아래 `▶` 를 누릅니다 (`Space`) |
| 한 영상만 재생 | 칸 머리글의 `▶` 를 누르거나 그 칸을 **더블클릭** |
| 조작 대상 바꾸기 | 칸을 클릭하면 **활성 칸**(파란 테두리)이 됩니다. 아래 컨트롤과 시간 표시는 이 칸 기준입니다 |
| 여러 영상 같은 위치로 이동 | 체크된 칸들이 재생 바 · 번호 이동 · 배속을 **함께** 따릅니다 |
| 칸 비우기 | 우클릭 → **비우기** |

아래 컨트롤이 **어느 칸에 적용되는지**는 이 규칙을 따릅니다.

- 활성 칸이 **체크되어 있으면** → 체크된 칸 전부 (동시 재생 · 동시 이동)
- 활성 칸이 **체크되어 있지 않으면** → 활성 칸 하나만 (원하는 영상만 재생)

상태 표시줄에 `대상 n개 · 재생 n / 열린 화면 n개` 로 지금 대상이 몇 칸인지 나옵니다.
분할을 줄여서 열려 있는 칸이 닫히게 되면 먼저 확인 창을 띄웁니다.

## 구간 잘라 저장 (편집)

원하는 구간만 골라 이미지 프레임들로 풀거나 동영상으로 다시 묶을 수 있습니다.
이미지 폴더를 동영상으로, 동영상을 이미지 폴더로 바꾸는 것도 같은 기능으로 됩니다.

1. 보고 싶은 프레임에서 `[ 구간 시작` (`I`) 을 누릅니다.
2. 끝낼 프레임에서 `구간 끝 ]` (`O`) 을 누릅니다. 재생 바에 구간이 띠로 표시됩니다.
3. `구간 재생` 으로 잘린 구간만 확인합니다. `반복` 이 켜져 있으면 구간 안에서만 돕니다.
4. `구간 저장…` (`Ctrl+E`) 을 누르고 **저장 형식** 을 고릅니다.
   버튼 옆 화살표를 누르면 `이미지 프레임 폴더로 저장` / `동영상 파일로 저장` 을
   바로 고를 수 있고, 칸 우클릭 메뉴에도 같은 두 항목이 있습니다.
   한 번 고른 형식은 다음 저장 때도 그대로 열립니다.

**이미지 폴더도 동영상으로 저장됩니다.** 소스 종류와 저장 형식은 따로입니다.
이미지 폴더의 구간을 동영상으로 묶을 때는 아래쪽 `기준 속도` 값이 기본 프레임
속도로 들어가고, 저장 창에서 다르게 정할 수도 있습니다.

**이미지 프레임 폴더로 저장**

| 항목 | 설명 |
|---|---|
| 저장 폴더 | 없으면 새로 만듭니다. 이미 파일이 있으면 먼저 확인합니다 |
| 파일 이름 앞부분 | `이름_0012.png` 처럼 원본 프레임 번호가 붙습니다 |
| 이미지 형식 | PNG, JPEG, WebP, BMP |
| 품질 | JPEG, WebP 에만 적용됩니다 |

**동영상 파일로 저장**

| 항목 | 설명 |
|---|---|
| 저장 파일 | 확장자로 컨테이너가 정해집니다 (`.mp4`, `.mkv`, `.avi`, `.mov`) |
| 코덱 | H.264, MPEG-4, FFV1(무손실) |
| 프레임 속도 | 기본값은 원본의 기준 속도입니다. 값을 바꾸면 느리거나 빠른 영상이 됩니다 |
| 화질 | 10 에 가까울수록 화질이 좋고 용량이 큽니다 |

`저장 간격` 을 2 이상으로 하면 프레임을 그만큼 건너뛰며 저장합니다.
동영상으로 저장하는 기능은 `imageio-ffmpeg` 가 있어야 씁니다. 없으면 저장 형식에서
동영상 항목이 잠기고, 어느 파이썬에 무엇을 설치해야 하는지 알려 줍니다.
저장은 별도 스레드에서 돌고 진행 창에서 **취소**할 수 있습니다.
취소하면 그때까지 저장된 파일은 그대로 남습니다.

구간 표시는 화면(칸)마다 따로 갖습니다. 멀티 뷰에서는 머리글에 `✂ 시작~끝` 으로
표시되고, 저장은 **활성 칸** 의 구간을 대상으로 합니다.
구간 시작·끝 표시는 다른 컨트롤처럼 대상 칸 전체에 함께 적용됩니다.

## 설치

```bash
pip install -r requirements.txt
```

`imageio-ffmpeg` 가 ffmpeg 바이너리를 함께 설치하므로 별도 설치는 필요 없습니다.
이미지 폴더만 볼 거라면 PyQt6 와 numpy 만 있어도 됩니다.

## 바탕화면 아이콘으로 등록 (더블클릭 실행)

```bash
./install.sh
```

설치하면 세 곳에 등록됩니다.

- **바탕화면** 의 `Data Player` 아이콘 — 더블클릭하면 바로 실행됩니다
- **Activities**(윈도우 키) 검색 — "Data Player" 또는 "데이터 플레이어"
- 동영상 파일 **우클릭 → 다른 프로그램으로 열기**

sudo 가 필요 없고, 건드리는 파일은 전부 홈 디렉터리 아래입니다.

| 위치 | 내용 |
|---|---|
| `~/.local/share/applications/data-player.desktop` | 앱 메뉴 항목 |
| `~/Desktop/data-player.desktop` | 바탕화면 아이콘 |
| `~/.local/share/icons/hicolor/*/apps/data-player.*` | 아이콘 (16~512px + SVG) |
| `.python-path` | 설치할 때 찾은 python 경로 |

**동영상 파일 연결에 대해** — 설치하면 mp4 등 동영상 형식이 Data Player 에
연결되어 우클릭 메뉴에 나타납니다. 시스템에 다른 동영상 플레이어가 없으면
Data Player 가 **기본 프로그램**이 될 수 있습니다 (설치 후 안내 메시지로
알려 줍니다). 원하지 않으면 연결 없이 설치할 수 있습니다.

```bash
./install.sh --no-mime      # 바탕화면 아이콘만 만들고 파일 연결은 안 함
./install.sh --uninstall    # 등록 해제 (프로젝트 파일은 그대로)
```

## 터미널에서 실행

```bash
python3 data_player.py                  # 빈 창으로 시작
python3 data_player.py /경로/이미지폴더    # 폴더를 바로 열기
python3 data_player.py /경로/영상.mp4     # 동영상을 바로 열기
./launch.sh /경로/영상.mp4                # 래퍼로 실행 (python 자동 탐색)
```

창에 폴더나 파일을 **끌어다 놓아도** 열립니다.
이미지 파일 하나를 놓으면 그 파일이 있는 폴더가 열리고 해당 이미지부터 시작합니다.

## 조작

| 키 | 동작 |
|---|---|
| `Space` | 재생 / 일시정지 |
| `←` `→` | 한 프레임 뒤로 / 앞으로 |
| `Home` `End` | 처음 / 끝으로 |
| `↑` `↓` | 배속 올리기 / 내리기 |
| `I` `O` | 구간 시작 / 끝 표시 |
| `Ctrl+E` | 구간 저장 |
| `Ctrl+O` | 이미지 폴더 열기 (활성 칸에) |
| `Ctrl+Shift+O` | 동영상 열기 (활성 칸에) |
| 칸 더블클릭 | 그 칸만 재생 / 일시정지 |
| 칸 우클릭 | 그 칸의 열기 / 비우기 메뉴 |

- **기준 속도(fps)** — 이미지 폴더에는 원래 fps 가 없으므로 여기서 정합니다(기본 30).
  최종 재생 속도는 `기준 속도 x 배속` 이고 상태 표시줄에 표시됩니다.
  동영상은 파일에 기록된 fps 를 쓰므로 이 칸이 잠깁니다.
- 숫자 입력칸은 **Enter** 를 누르거나 `이동` 버튼을 누를 때 이동합니다.

## 동작 방식 메모

- 재생은 타이머 횟수가 아니라 **경과 시간**으로 현재 프레임을 계산합니다.
  디코딩이 느려도 배속이 느려지지 않고, 대신 프레임을 건너뜁니다.
- 동영상은 순차 재생 시 ffmpeg 파이프 하나를 계속 읽고,
  뒤로 가거나 60 프레임 넘게 건너뛸 때만 `-ss` 로 파이프를 다시 엽니다(프레임 단위 정확, 약 50ms).
- 디코딩한 프레임을 LRU 로 캐시합니다(단일 화면 48장, 멀티 뷰는 칸 수로 나눠 씁니다).
- 멀티 뷰는 칸마다 재생 시계를 따로 두고, 창의 타이머 하나가 모든 칸을 돌립니다.
  타이머 주기는 재생 중인 칸 가운데 가장 빠른 속도에 맞춥니다.
- 구간 저장은 작업 스레드에서 소스를 **새로 열어** 처리합니다. 화면이 쓰는 ffmpeg
  파이프와 섞이지 않게 하려는 것이고, 저장하는 동안 재생은 잠시 멈춥니다.
- 이미지 폴더를 동영상으로 저장할 때 크기가 다른 이미지가 섞여 있으면 첫 프레임
  크기에 맞춰 비율을 유지하며 검은 여백을 넣습니다.
- 동영상 길이는 `duration x fps` 로 추정하고, 끝에서 실제 길이를 만나면 자동으로 보정합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `data_player.py` | 애플리케이션 본체 |
| `launch.sh` | 실행 래퍼 — PyQt6 가 있는 python 을 찾고, 실패하면 오류 창을 띄웁니다 |
| `install.sh` | 바탕화면/메뉴 등록 및 해제 |
| `assets/` | 아이콘 (`make_icon.py` 로 다시 만들 수 있습니다) |

## 한계

- 디코딩은 GUI 스레드에서 합니다. 아주 큰 이미지(수천만 화소)를 높은 배속으로 재생하면 프레임 건너뜀이 눈에 띌 수 있습니다. 멀티 뷰로 큰 영상 여러 개를 동시에 재생할 때도 마찬가지입니다(재생 속도는 유지되고 대신 프레임을 건너뜁니다).
- 오디오는 재생하지 않습니다(프레임 뷰어 목적).
